# 小贝自然步态

## 已确认需求

2026-09-20，Ethan 选择方案 A：保留现有布偶猫画风，动作像真实猫咪，四足走路、自然起停和转身。实查 Idle 素材为像素风，不能因“仿生”而换成写实照片或另一只猫。

## 当前证据

- `renderer/pet.js` 的 `PET_ANIMS` 没有 walk，走动复用 idle。
- `renderer/pet.css` 的 `pet-hop` 对整张坐姿图执行弹跳、压缩和旋转。
- `startWalk()` 直接设定随机速度并翻转朝向；`loop()` 匀速移动后立即进入 rest。
- 当前位移计时与序列帧播放独立，不能使着地脚掌稳定。

## 素材与实现规格

1. 保留蓝眼睛、面部花纹、奶白毛色、深色耳尾和原有像素颗粒。以 `renderer/assets/pet/Idle/xiaobei-ragdoll-idle-01.png` 为角色参考。
2. 新增侧身四足站姿与完整慢走周期。各帧统一画布、猫咪体积与足底基线，尾巴完整不裁切；保持四肢身份连续，避免多腿、融肢、毛色闪烁。
3. 四肢分时抬落，支撑期脚掌相对地面稳定，摆动期抬脚前送；躯干只随承重轻微起伏，不整张跳跃或挤压。
4. 补齐坐姿至站姿及站姿至坐姿过渡，转向先减速再转换朝向，不在行走中突然镜像翻转。
5. 行走相位由实际移动距离推进，步幅随尺寸缩放；平滑加减速。路径需消除终点竖向吸附，先保证横向走动可信。
6. 互动和提醒需要停止移动，并保持既有点击、双击、对话、鼠标穿透、位置保存和减少动态效果行为。

- 本文件保存确认的偏好、实施规格与后续进展。
- 生成源图、提示词、生成记录放 `docs/assets/pet-gait/`。

- 对比截图、动画预览放 `docs/screenshots/pet-gait/`。

## 验收

- 在 64 / 96 / 128 px 三档下检查行走循环接缝、着地滑动、角色一致性、起停与转向。
- 检查左右移动、到达边界、对话打断、提醒动作、尺寸变化与减少动态效果。
- 对运动相位和位移关系、减速到达及暂停恢复进行行为测试，运行 `npm test`。
- 实际浏览器或 Electron 画面验证后再更新 README 中的行为说明。

## v3 复核与修正（2026-09-20 晚，父代理独立验收）

### 修正 1：绿幕溢色实际未清理（已修）

`clean-pet-asset-edges.py` 依赖的 `remove_chroma_fringe()` 只处理**透明像素 ±2px 内的边缘像素**，
且处理方式是**整块置为透明**。因此：

- 白毛**内部**的溢色被完全跳过。逐帧对比备份证实：84 张非 Walk 帧的偏绿像素数与备份**完全一致**
  （Idle 843=843、Guiding 276=276…），即"统一清理绿幕色偏"对这批素材没有产生任何效果；
  只有 Walk 真的清了（4755 → 64，来自另一条生成管线）。
- 溢色特征：浅色毛上绿通道比 max(R,B) 高最多 16（采样 `rgb(237,251,235)`，纯毛色应约 `rgb(248,248,232)`）。
- 用删像素的方式处理会啃掉轮廓——这正是之前耳朵被误删的机制。

新增 `scripts/fix-pet-green-spill.py`：**只改写绿通道**，把 `G` 压到 `max(R,B)`，不动 alpha/红/蓝。
执行结果 92 帧共 62,228 像素被修正。逐像素对比备份的严格校验：alpha 变化 0、红蓝变化 0、
绿只降不升（单像素最大下调 16）、可见边界变化 0 帧。复核后所有动画的偏绿像素归零（最大残留 cast=1）。
前后对比图：`docs/screenshots/pet-gait/green-spill-fix-comparison.png`。

### 修正 2：桌宠不该压在用户所有窗口之上（已修）

用户反馈"他应该在桌面，而不是在我的每个窗口前面"。原实现是 `setAlwaysOnTop(true, 'screen-saver', 0)`。

查 Electron 官方文档确认：macOS 真正能放到桌面背景层的 `type: 'desktop'`（kCGDesktopWindowLevel - 1）
**不接收焦点、键盘和鼠标事件**——用它宠物将完全无法点击与拖动。
因此改为**普通窗口层级**：`alwaysOnTop: false`，`setVisibleOnAllWorkspaces(true, { visibleOnFullScreen: false })`。
面板与提醒仍保持置顶（它们是瞬间出现的工具，不是常驻层）。

### 修正 3：新增拖拽（原方案列为 L1 但从未实现）

- 指针按下后移动超过 4px 进入拖拽：暂停自主走动、`setPointerCapture`、窗口强制保持可交互
  （`refreshHitRegion` 在拖拽期间不再切回穿透，否则快速拖动会甩掉宠物）。
- 位移 1:1 跟随，拖拽期间**关闭舞台 transform 过渡**（该规则必须写在 idle/rest 过渡规则之后，
  同特异性下后写者生效，否则宠物会缓动"飘"在指针后面）。
- 纵向范围放宽到「底部安全距 — 顶部安全距」，不再受自主走动那条 30% 窄带限制。
- 拖拽中播放 Petting（被抱起来）并循环；松手强制保存位置；紧随的 click 被吞掉，不会拖完弹出气泡。
- 光标 `grab` / `grabbing`。
- 实机验证：请求位移 (80, -40) 实测 (80, -40)，同一次拖拽内连续两次移动正确累积，
  拖后不弹气泡、纯点击仍正常弹气泡。
